Решение кейса «Динамическое ценообразование авиабилетов». Блок «Бизнес и аналитика»

Гутенко Иван Никитич

Обозначения: цены p в тыс. руб., q — проданные билеты, f — число перелётов. Индексы: П — Петербург, М — Москва, С — Сочи. Все деньги в тыс. руб.

Обратные функции спроса (выражаем цену через q): pПМ = 10 − q/20; pМП = 8 − q/20; pМС = 6 − q/20; pСМ = 5 − q/20; pПС = 10 − q/10; pСП = 8 − q/10.

Задание 1.1

С→Мрынок С→М + транзит С→П (1-й перелёт)

Задание 1.2. Ограничения

  1. Кресла (правила 1, 3): qПМ + qПС ≤ 150·fПМ; qМС + qПС ≤ 150·fМС; qСМ + qСП ≤ 150·fСМ; qМП + qСП ≤ 150·fМП. — В самолёте 150 мест; транзитный пассажир занимает кресло на каждом из двух перелётов, поэтому конкурирует за места сразу с двумя прямыми рынками.
  2. Не больше 4 перелётов (правило 2): fПМ + fМП + fМС + fСМ ≤ 4. — Экипаж и самолёт физически успевают только 4 полёта в день.
  3. Вернуться туда, где был утром (правило 2): fПМ = fМП, fМС = fСМ (сколько раз прилетели в город, столько и улетели). Утром самолёт в П, поэтому fМС > 0 возможно только при fПМ ≥ 1. — Самолёт не может «застрять» в чужом городе: завтра он нужен там же, где начинал. Допустимые маршруты из П: стоять; П→М→П; П→М→П→М→П; П→М→С→М→П.
  4. Целые неотрицательные числа (правила 1, 2): f ∈ {0, 1, 2, …}; q ≥ 0; p ≥ 0. — Нельзя сделать полрейса или продать отрицательное число билетов.
  5. Порядок транзита (правило 3): qПС > 0 только если в маршруте есть перелёт М→С позже П→М; qСП > 0 только если есть М→П позже С→М. — Транзит продаётся только тогда, когда стыковка реально существует в этот день (маршрут П→М→С→М→П её даёт).
  6. Одна цена — спрос по функции (правило 4): qПМ = 200 − 20pПМ, qМП = 160 − 20pМП, qМС = 120 − 20pМС, qСМ = 100 − 20pСМ, qПС = 100 − 10pПС, qСП = 80 − 10pСП. — Компания выбирает только цену; сколько людей купит, решает рынок. Поэтому продать меньше спроса можно только поднятием цены.
  7. Регулятор (правило 7): pПС ≤ pПМ + pМС; pСП ≤ pСМ + pМП. — Транзит не может стоить дороже, чем те же два перелёта отдельными билетами.

Задание 1.3. Прибыль за день

Прибыль = Выручка − Затраты на пассажиров − Затраты на перелёты

Выручка = pПМqПМ + pМПqМП + pМСqМС + pСМqСМ + pПСqПС + pСПqСП

Затраты на пассажиров = 1·(qПМ + qМП + qМС + qСМ) + 2·(qПС + qСП)

Затраты на перелёты = 100·(fПМ + fМП + fМС + fСМ)

Удобная запись: Прибыль = Σрынки (p − c)·q − 100·Σf, где c = 1 для прямого рынка и c = 2 для транзитного.

Часть 2. Обычный день (маршрут П→М→С→М→П, все f = 1)

Задание 2.1

Для рынка со спросом q = a − b·p и затратами c на пассажира прибыль равна (p − c)(a − b·p). Это парабола с ветвями вниз, её максимум в точке, где производная равна нулю: a − 2b·p + b·c = 0, откуда p* = (a/b + c)/2 и q* = (a − b·c)/2. Затраты на перелёт от цен не зависят и на выбор цены не влияют.

Часть 3. Пиковый день (qПМ = 360 − 20pПМ)

Задание 3.1

p* = (360/20 + 1)/2 = 9,5, q* = 360 − 190 = 170. Ограничение по креслам П→М нарушено: 170 + 40 (транзит) = 210 > 150. Даже без транзита 170 > 150.

Задание 3.2

Активно только ограничение qПМ + qПС ≤ 150. Остальные перелёты загружены слабо, поэтому рынки М→П, М→С, С→М и С→П сохраняют цены из части 2. 150 кресел П→М нужно разделить между прямыми и транзитными пассажирами так, чтобы последнее кресло приносило одинаковую прибыль на обоих рынках.

Предельная прибыль (производная (p − c)q по q): для П→М: 18 − q/10 − 1 = 17 − qПМ/10; для П→С: 10 − q/5 − 2 = 8 − qПС/5. Приравниваем обе величины к λ (ценности одного кресла): qПМ = 170 − 10λ, qПС = 40 − 5λ. Их сумма равна 150, то есть 210 − 15λ = 150, отсюда λ = 4.

Задание 3.3

Ценность кресла λ = 4: одно дополнительное кресло на П→М добавляет около 4 тыс. руб. прибыли. Точный пересчёт при 151 кресле: λ меняется от 4 до 3,93, прирост ≈ (4 + 3,93)/2 ≈ 3,97 тыс. руб. (при целом числе билетов перебор даёт 1628,95 − 1625 = 3,95). В обычный день на П→М и так пустуют 20 кресел (ограничение неактивно, λ = 0), поэтому 151-е кресло ничего бы не дало: продавать его некому, если не снижать цену ниже оптимальной.

Задание 3.4

  • Почему изменились цена и продажи транзита. Транзитный пассажир занимает кресло П→М, а оно теперь дефицитно: это же кресло можно продать прямому пассажиру и заработать λ = 4 тыс. Значит, для транзита к прямым затратам 2 добавляются альтернативные издержки 4, всего 6. Цена p = (10 + 6)/2 = 8 вместо 6, продажи 20 вместо 40.
  • Загрузка М→С упала с 90 до 70 человек (пустых кресел 80 вместо 60). Пик в П→М «перетёк» на соседний перелёт.
  • Почему транзит дешевле прямого билета. Цена определяется спросом своего рынка, а не расстоянием. Транзитный спрос (100 − 10p) намного меньше и чувствительнее к цене, чем пиковый П→М (360 − 20p). По 11,5 тыс. транзит не купил бы никто: 100 − 115 < 0. Регулятор задаёт только верхнюю границу цены (15), нижней нет.
  • Почему это выгодно. Последний транзитный пассажир приносит компании столько же, сколько последний прямой (λ = 4 у обоих). В среднем транзит даёт (8 − 2) = 6 тыс. с человека, да ещё и занимает кресло М→С, которое иначе пустовало бы. Если полностью отказаться от транзита (qПМ = 150, p = 10,5), прибыль П→М вырастет до 1425, но потеряются 120 от транзита: 1425 < 1365 + 120 = 1485.

Часть 4. Маршрут самолёта

Задание 4.1

Маршрут П→М→П→М→П: fПМ = fМП = 2, в Сочи не летаем. Значит, рынки М→С, С→М, П→С и С→П не обслуживаются (q = 0). На П→М теперь 300 мест, и оптимум без ограничений q = 170 ≤ 300 помещается: p = 9,5, прибыль (9,5 − 1)·170 = 1445. М→П: 70 ≤ 300, p = 4,5, прибыль 245. Перелётов по-прежнему 4.

Прибыль = 1445 + 245 − 400 = 1290 тыс. руб. против 1625 в задании 3.2.

Предложение невыгодно: прибыль уменьшится на 335 тыс. руб. (−21%).

Почему: (1) Второй рейс П→М добавляет всего 1445 − 1365 = +80. Он позволяет продать 170 билетов П→М вместо 130 (+40), но только при снижении цены с 11,5 до 9,5 для всех, а 130 мест из 300 всё равно летят пустыми. (2) Второй рейс М→П не даёт ничего: спрос 70 и так помещался в один самолёт. (3) Теряется вся прибыль сочинского направления: 125 + 80 + 120 + 90 = 415. Коллега сравнивает цены билетов, а нужно сравнивать прибыль рейса. Дешёвые билеты М→С всё равно покрывают переменные затраты и вместе с транзитом окупают перелёт.

Часть 5. Снегопад (π = 0,2)

Задание 5.1

Снегопада нет (0,8): прибыль рынка (p − 1)·q. Снегопад (0,2): деньги возвращаются, компенсация 4 на пассажира, затрат нет: −4q.

E[ППМ] = 0,8·(p − 1)(200 − 20p) − 0,2·4·(200 − 20p) = 0,8·(p − 2)·(200 − 20p)

Риск работает как дополнительные затраты 0,2·4/0,8 = +1 тыс. руб. на каждого пассажира (и на транзитного тоже: билет у него один). Ожидаемые затраты на перелёты 0,8·400 = 320 от цен не зависят.

Задание 5.2

Применяем ту же формулу с c' = c + 1: p* = (a/b + c + 1)/2, то есть каждая цена выше на 0,5.

Задание 5.3

Средняя прибыль = 0,8·(прибыль без снегопада) + 0,2·(−4·Σq).

  • Цены части 2: 0,8·705 − 0,2·4·320 = 564 − 256 = 308 тыс. руб.
  • Новые цены: прибыль без снегопада = 5·80 + 4·60 + 3·40 + 2,5·30 + 4,5·35 + 3,5·25 − 400 = 680; средняя = 0,8·680 − 0,2·4·270 = 544 − 216 = 328 тыс. руб.
Учёт риска даёт +20 тыс. руб. (+6,5%) средней прибыли за день D.

Почему продавать меньше выгодно: каждый проданный билет теперь несёт ожидаемый убыток 0,2·4 = 0,8 тыс. (компенсация), а его выручка с вероятностью 0,2 возвращается. При старых ценах последний билет давал нулевую предельную прибыль в хорошую погоду и минус 0,8 в среднем. Поднимая цену, мы отказываемся от самых «дешёвых» пассажиров, которые в среднем приносят убыток. Без снегопада компания теряет 705 − 680 = 25, но в снегопад экономит 1280 − 1080 = 200 компенсаций: 0,2·200 > 0,8·25.

Часть 6. Экономические выводы

Задание 6.1. Роль ограничений

  1. Ограничение по креслам неважно в обычный день и решает всё в пиковый. В обычный день даже на самом загруженном П→М остаётся 20 пустых кресел, лишнее кресло стоит 0 и цены равны «свободным» (части 2, 3.3). В пик спрос на П→М (210 при свободной цене) превышает 150 мест. Тогда кресло стоит 4 тыс., цена П→М растёт с 9,5 до 11,5, а прибыль дня — с 705 до 1625 (3.2).
  2. Регуляторный потолок на транзит неважен при текущем спросе. Во всех сценариях оптимальная цена транзита намного ниже суммы прямых: 6 ≤ 9 (обычный), 8 ≤ 15 (пик), 6,5 ≤ 10 (снегопад). Ограничение начнёт влиять, только если транзитный спрос вырастет настолько, что его свободная цена превысит сумму прямых.
  3. Ограничение «≤ 4 перелёта, вернуться домой» важно при выборе маршрута. Перелёт можно «потратить» на перегруженное направление только ценой целого направления. В пик замена Сочи на второй круг П↔М даёт +80 на П→М, но теряет 415 на сочинских рынках: прибыль падает на 335 (4.1).
  4. Риск отмены важен, когда компенсация велика относительно маржи. При π = 0,2 и компенсации 4 тыс. каждый билет фактически дорожает на 1 тыс. (5.1). Оптимальные цены растут на 0,5, продажи падают с 320 до 270, средняя прибыль растёт с 308 до 328 (5.3). При π = 0 надбавка нулевая.

Задание 6.2. Одно кресло — разные цены

  1. П→М в пиковый день: 5,5 → 11,5 тыс. Самолёт и маршрут те же, вырос спрос и кресла стали дефицитом (2.1 → 3.2).
  2. Транзит П→С в пиковый день: 6 → 8 тыс., хотя спрос на транзит не изменился. Подорожало кресло на перелёте П→М, которое транзит разделяет с прямыми пассажирами (3.4).
  3. Все шесть рынков при угрозе снегопада: каждая цена +0,5 тыс. (например, П→М 5,5 → 6). Спрос и маршрут те же, вырос риск (5.2).

Задание 6.3. Правила для руководства

  1. Если при «свободных» ценах (p = (a/b + c)/2) пассажиров на перелёте больше 150, то поднимать цены на всех рынках этого перелёта, включая транзит, пока он не заполнится ровно. Места делить так, чтобы последнее кресло давало одинаковую прибыль на каждом рынке: к затратам на пассажира прибавить ценность кресла λ (3.2, 3.4: λ = 4, П→М 11,5, транзит 8).
  2. Если есть вероятность отмены π с компенсацией K на пассажира, то считать цену так, будто затраты на пассажира выше на π·K/(1 − π). При π = 0,2, K = 4 это +1 тыс., цены +0,5 (5.1–5.3: +20 тыс. в среднем).
  3. Если хочется перенести рейсы на перегруженное направление, то сравнивать полную прибыль маршрутов с пересчитанными ценами, а не цены билетов. Дополнительный рейс выгоден, только если прирост на перегруженном рынке больше прибыли всех рынков, которые теряются, включая транзит (4.1: +80 против −415).

Задание 6.4. Главные упрощения

  1. Спрос известен точно. В реальности спрос случаен (см. квантили прогноза в ML-части). Тогда и в обычный день П→М иногда переполнялся бы, и у кресла была бы ненулевая ценность. Вывод 1 («в обычный день ограничение неважно») смягчился бы: оптимальные цены обычного дня были бы немного выше 5,5, а выгода дополнительного кресла была бы положительной. Появился бы смысл в овербукинге.
  2. Одна цена на рынок на весь день, снегопад отменяет всё без переноса. Реальные авиакомпании продают несколько тарифов по мере заполнения и пересаживают пассажиров отменённого рейса на другой день. С несколькими тарифами пиковая прибыль была бы выше 1625, а вытеснение транзита слабее: дешёвые места продаются транзиту раньше, дорогие — прямым позже. С переносом пассажиров ожидаемые потери от снегопада меньше, поэтому надбавка за риск (вывод 4) была бы меньше 0,5 тыс., а разница 308 → 328 сократилась бы.
