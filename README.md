# Динамическое ценообразование авиабилетов — турнир «Решись», направление «Технологии»

Решение задачи продвинутого уровня. Автор: **Гутенко Иван Никитич**.

**Веб-приложение: https://gut-server.tail147b9d.ts.net/** (демо-аккаунт `jury_demo` / `reshis2026`)

| Блок | Что внутри | Главный результат |
|---|---|---|
| [Бизнес и аналитика](business/) | `Гутенко_Иван_Никитич_БиА.pdf` — модель дня, оптимальные цены, маршрут, риск снегопада, выводы; `check_optimum.py` — проверка оптимумов перебором | обычный день 705 тыс. ₽, пиковый 1625 тыс. ₽ (ценность кресла 4 тыс. ₽); маршрут П↔М×2 хуже на 335 тыс. ₽; учёт снегопада +20 тыс. ₽ |
| [Искусственный интеллект](ml/) | `ml_demand_forecast.ipynb` — исследование данных, AutoGluon, признаки праздников, выбор модели, тест, прогноз; `my_forecast.csv` — прогноз спроса и цен на 01.06–01.07.2026 | Chronos-2 + признаки дат: MAE на валидации 35,9 (SeasonalNaive 51,5), на тесте 44,1 (8–10% спроса) |
| [Разработка](dev/) | вариант C: веб-страница + backend API на Python, скрипт (вариант A), тесты, Dockerfile | регистрация, авторизация, график распределения спроса, хостинг |

## Быстрый запуск веб-приложения

```bash
cd dev
python3 server.py            # http://127.0.0.1:8000
python3 -m unittest test_app # тесты
```

Подробности — в [dev/README.md](dev/README.md).

## Инструменты

Python, pandas, AutoGluon (Chronos-2), стандартная библиотека Python для сервера, чистый JavaScript + SVG на фронтенде,
Docker, Tailscale Funnel. Использованные инструменты ИИ: **Claude Code** (модель Claude Opus 5.5).
